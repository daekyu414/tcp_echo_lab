# TCP Echo Lab

Python 소켓으로 구현한 간단한 TCP 에코 서버·클라이언트 실습입니다.  
클라이언트가 전송한 메시지를 서버가 그대로 돌려주는 과정을 실행하고, 제공된 패킷 캡처로 TCP 연결 흐름을 확인할 수 있습니다.

## 구성

```text
tcp_echo_lab/
├── tcp_server.py   # TCP 에코 서버
├── tcp_client.py   # 테스트 클라이언트
└── tcp9000.pcap    # 루프백 인터페이스 패킷 캡처
```

## 동작 방식

1. 서버가 `127.0.0.1:9000`에서 연결을 기다립니다.
2. 클라이언트가 서버에 접속해 `Hello network`를 전송합니다.
3. 서버는 받은 데이터를 변경하지 않고 다시 전송합니다.
4. 클라이언트가 응답을 출력하고 연결을 종료합니다.

## 실행 방법

Python 3만 있으면 별도 패키지 설치 없이 실행할 수 있습니다.

먼저 터미널에서 서버를 실행합니다.

```bash
python3 tcp_server.py
```

다른 터미널에서 클라이언트를 실행합니다.

```bash
python3 tcp_client.py
```

클라이언트에서는 다음 응답을 확인할 수 있습니다.

```text
b'Hello network'
```

서버에는 수신한 데이터 크기인 `13`이 출력됩니다.

## 패킷 캡처 살펴보기

`tcp9000.pcap`을 Wireshark로 열고 다음 필터를 적용하면 이 실습의 트래픽만 볼 수 있습니다.

```text
tcp.port == 9000
```

캡처에는 다음 과정이 포함되어 있습니다.

- `SYN → SYN, ACK → ACK` 연결 수립
- 클라이언트의 13바이트 데이터 전송
- 서버의 동일한 13바이트 에코 응답
- `FIN, ACK`를 통한 연결 종료

터미널에서는 `tcpdump`로도 확인할 수 있습니다.

```bash
tcpdump -nn -r tcp9000.pcap
```

## 주요 설정

| 항목 | 값 |
|---|---|
| 프로토콜 | TCP/IPv4 |
| 주소 | `127.0.0.1` |
| 포트 | `9000` |
| 서버 대기 큐 | `128` |
| 연결 타임아웃 | 5초 |
| 수신 버퍼 | 4096바이트 |

## 참고

- 서버는 한 번에 하나의 클라이언트 연결을 처리하는 학습용 구현입니다.
- 루프백 주소에 바인딩하므로 같은 컴퓨터 안에서만 접속할 수 있습니다.
- 서버를 종료하려면 서버 터미널에서 `Ctrl+C`를 누르세요.
